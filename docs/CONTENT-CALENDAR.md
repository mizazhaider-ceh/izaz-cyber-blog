## How to use this file

- When an article is published, move its row to published: record the real publish date and the article slug, and add the article to `docs/CONTENT.md`.
- When a slot slips, change only its date, forward, and note the change in one line below the table.
- When a slot is dropped, mark it dropped with a one-line reason. Do not delete the row, so the plan stays honest.
- Add the next slots when fewer than 3 planned slots remain, keeping the same 1 to 2 week cadence.
